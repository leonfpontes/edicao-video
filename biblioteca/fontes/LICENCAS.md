# Fontes da biblioteca

Todas com licença livre para uso comercial e para embutir em vídeo. As de estilo (`motor/estilos.py`) foram baixadas do
repositório oficial do Google Fonts (`github.com/google/fonts`, pasta `ofl/`).

| Arquivo | Família | Licença | Uso |
|---|---|---|---|
| `Roboto-*.ttf` | Roboto | Apache 2.0 | Texto e títulos das marcas |
| `Inter-*.ttf` | Inter | SIL OFL 1.1 | Texto e títulos das marcas |
| `Fraunces-*.ttf` | Fraunces | SIL OFL 1.1 | Títulos das marcas |
| `DMSerifDisplay-Regular.ttf`, `DMSerifDisplay-Italic.ttf` | DM Serif Display (Adobe/Google) | SIL OFL 1.1 | Estilo: `serifa`, `serifa_italica` (número do passo) |
| `Anton-Regular.ttf` | Anton | SIL OFL 1.1 | Estilo: `condensada` (texto atrás da pessoa, títulos editoriais) |
| `SpaceMono-Regular.ttf`, `SpaceMono-Bold.ttf` | Space Mono | SIL OFL 1.1 | Estilo: `mono` (anotações, HUD, rótulo de som) |
| `Caveat-Variable.ttf` | Caveat | SIL OFL 1.1 | Estilo: `manuscrita` (neon, títulos editoriais) |
